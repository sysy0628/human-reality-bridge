## Weather and geocoding data

### Open-Meteo

- Website: https://open-meteo.com/
- API documentation: https://open-meteo.com/en/docs
- Licence information: https://open-meteo.com/en/licence
- Terms: https://open-meteo.com/en/terms

Weather, air-quality and geocoding requests are made to Open-Meteo services. Open-Meteo API data are provided under CC BY 4.0 and require attribution. The free/open-access API is restricted by Open-Meteo's current terms to non-commercial use and published rate limits. Commercial operators must independently obtain an appropriate Open-Meteo paid plan and comply with all applicable upstream data-source terms.

The card displays a visible “Weather data by Open-Meteo.com” link near the weather data source. This project does not imply endorsement by Open-Meteo.
